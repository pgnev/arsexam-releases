# ArsExam 4.1.5 — корекция на документацията и пакетите

Версия на приложението 4.1.5; Microsoft Store MSIX 4.1.5.0; Windows x64.

4.1.5 поправя несъответствието, при което Portable README на 4.1.4 още описва 4.1.2. Обновени са номерът на версията, README, START_HERE, потребителските ръководства и версията на приложимата EULA преди изграждане. Не се променят лицензионни условия, издадени права, работни банки, диагностично или имейл съгласие.

Поведенческите поправки от 4.1.4 са запазени: защитено стартиране, явни JSON договори за доброволни известия, възстановяване на разписки и правилно записване в уеб Owner Console. 4.1.5 не добавя нови функции.

Финалните Setup/Update/MSIX байтове се квалифицират отделно. Историческият таг v4.1.4 и неговият Store пакет остават непроменени. Публичното GitHub издание и Microsoft Store имат отделни процеси на публикуване. Актуалният публичен Stable се удостоверява чрез официалните Releases и Stable manifest, а не чрез наличието на локален пакет.
