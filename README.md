# ArsExam Desktop — Stable 4.1.5

**Текуща публична версия: 4.1.5** (Windows x64). Публикувана на 16 октомври 2026 г.

ArsExam е настолно приложение за създаване и управление на изпитни и учебни ресурси за ДЗИ по теория на професията „Музикално изкуство“. Инсталирането не предоставя автоматично право на използване — необходим е валиден цифрово подписан лиценз за конкретния потребител/институция и разрешените устройства.
