# Documentation freshness

Release documentation must stay synchronized with the authoritative Stable feed and latest public release. CI should fail publication when documented Stable version, asset names, or SHA-256 values drift from `update/stable-manifest.json` or `/releases/latest`.


## Подготовка за ArsExam 4.0.0

Клонът `docs/4.0.0-connectivity-licensing-20261005` подготвя документацията за изданията с актуализирания механизъм за лицензиране. Тези текстове не променят със задна дата условията на вече публикувания ArsExam 3.9.8 Stable. Публикуването им като текущи документи трябва да се извърши заедно с отделно квалифицирано издание, което действително включва описания механизъм.
