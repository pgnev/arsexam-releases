# ArsExam 4.1.2 — technical reference

## Издание и технология

ArsExam 4.1.2 е самостоятелно Windows x64 Desktop/Portable приложение, разработено с C# / WPF и .NET 10. Пакетите са self-contained. Източникът за това издание е immutable private Git tag v4.1.2, commit 7b3710377fbce8288b1488877e6a28b7ed2c3999.

GitHub Setup/Update се разпространяват отделно от Microsoft Store MSIX. GitHub Stable версията се определя от публичния release и update/stable-manifest.json; наличието на локално компилиран пакет или source tag не е само по себе си публикация.

## Поправка преди активация

В 4.1.1 прозорецът „Връзка с поддръжката“ е можел да отказва отваряне, когато се е стартирал от политиката за поверителност преди лицензна активация. 4.1.2 премахва зависимостта от услуги за диагностика/обновяване, които все още не са инициализирани, и използва локалните настройки, докато те не са налични.

Отварянето на прозореца не включва изпращане на диагностика, не създава съгласие и не изисква валиден лиценз. Прегледът и ZIP архивът на диагностичните данни са локални и се задействат изрично; потребителят сам решава дали да изпрати файл.

## Лицензиране и запазване на данните

Не са променени основните правила за цифрово подписан лиценз, ограниченията за устройства, 12-месечният стандартен срок, 30-дневните доброволни напомняния и 7-дневният условен гратисен период. Не е променен сървърният процес за отнемане или служебни известия.

Приложението пази постоянните директории Data, Media, Import, Export, Backup и Licensing отделно от версионираните изпълними файлове. Обновяването с Setup включва механизъм за rollback. Действителните тестове за 4.1.2 и техните ограничения са в QA-REPORT-4.1.2.md.

## Защита на бинарните файлове

Защитата на изпълнимите модули, SHA-256 хешовете, Authenticode подписването и ECDSA подписите на лицензите са отделни механизми. Официалните GitHub Setup/Desktop/Launcher бинарни файлове за 4.1.2 са установени като Authenticode NotSigned. Временни QA сертификати от Windows Sandbox не са издателски подпис и не се публикуват.
