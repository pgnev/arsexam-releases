# ArsExam Support

## Contact

Official support contact:

**petkoganev@gmail.com**

For normal product support, prefer the in-application **Help → Contact support** flow because it includes the ArsExam version and a support identifier without exposing examination content.

## What to include

A useful support request should contain:

- ArsExam version and distribution mode (Desktop/Portable);
- a short description of the problem;
- the exact steps that reproduce it;
- any error text shown by ArsExam;
- a minimal diagnostic/support bundle only when relevant.

## Do not send

Do not send plaintext passwords, Recovery Kits, complete databases, full examination-bank archives, confidential examination content, signing material or unrelated personal data by e-mail.

## Password recovery

Current ArsExam recovery is designed so that physical access to the computer alone is not sufficient to reset the local password. When secure online recovery is enabled, ArsExam creates an opaque one-time recovery request and support may issue a time-limited one-time code after verifying the request.

Support should never ask for the old password.

## Availability

Support is provided according to available capacity and is not a guaranteed service-level agreement unless explicitly agreed in writing.
