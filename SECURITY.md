# Security Policy

## Reporting a vulnerability

Please report suspected ArsExam security vulnerabilities **privately** to:

**petkoganev@gmail.com**

Use a clear subject such as `ArsExam security report` and include only the minimum information needed to reproduce and assess the issue.

Do **not** publish exploitable details, credentials, personal data, examination-bank content, Recovery Kits, passwords or private diagnostic material in a public GitHub issue.

## Scope

Security reports may cover, among other areas:

- authentication and password recovery;
- local data protection and unintended data disclosure;
- update integrity and rollback behavior;
- installer/launcher security;
- diagnostics/privacy boundaries;
- dependency vulnerabilities with a concrete impact on ArsExam.

## Sensitive material

If a report requires logs or a diagnostic bundle, use only the minimum relevant data. ArsExam support should never request your plaintext password or Recovery Kit.

## Disclosure

Please allow reasonable time for validation and remediation before public disclosure. No bug-bounty or guaranteed response-time program is currently offered unless explicitly announced in writing.
